Perl の定番モジュールと書き方を、25日で一通りたどる【Perl Advent Calendar 2025 目次】

Perl の正規表現・リファレンス・コンテキストといった基礎から、Web・データベース・非同期処理・テストまで、定番モジュールと書き方を25日で一通りたどる Perl Advent Calendar 2025 の目次です。

26, 2025
読了時間: 3分

2025年12月1日から25日まで、Perl の話題を1日1本ずつ書いたアドベントカレンダーです。言語の基礎（正規表現・リファレンス・コンテキスト）から、Web アプリ、データベース、非同期処理、テスト、依存関係の管理まで、実務でよく使う定番モジュールと書き方を一通り扱っています。

記事は AI を使って生成しました。どの日からでも読めます。

このページは目次を兼ねた案内板です。初めてなら「まず読むなら」の3本から、やりたいことが決まっているなら「目的から探す」から、日付で追いたいなら「日付順の一覧」から選んでください。

まず読むなら

  • リファレンス — 配列やハッシュを入れ子にする仕組み。Perl のコードを読むときに最初につまずく所で、ほかの記事を読む足場になる
  • コンテキスト — 同じ式がスカラーとリストで違う値を返す理由。Perl らしい書き方の大半はここから来ている
  • CPAN モジュール20選 — 実務で使うモジュールをカテゴリ別に一覧する回。残りの記事への索引としても使える

目的から探す

言語の基礎でつまずいている

  • 正規表現 — メタ文字・キャプチャ・先読みと後読み
  • リファレンス — 無名配列・無名ハッシュ・サブルーチンリファレンス
  • コンテキスト — スカラー・リスト・void と wantarray
  • Try::Tiny — eval より安全な例外処理
  • List::Util と List::MoreUtils — リスト処理の定番関数

コマンドラインの小さな道具を書きたい

  • ワンライナー — コマンドラインでのテキスト処理
  • Getopt::Long — コマンドライン引数の処理
  • 設定ファイル — YAML・JSON・TOML・INI を読む
  • ロギング — Log::Log4perl と Log::Dispatch

Web アプリや外部サービスとつなぎたい

  • Mojolicious — Mojolicious::Lite で始める Web 開発
  • Plack/PSGI — Perl の Web アプリを支える共通の仕組み
  • Web スクレイピング — Web::Scraper と Mojo::UserAgent
  • メール送信 — Email::Sender と Email::MIME

データを扱いたい

  • データベース — DBI・プレースホルダ・トランザクションと DBIx::Class
  • 日時処理 — 速くて正確な Time::Moment
  • 暗号化 — Crypt::* モジュール群

重い処理や待ち時間をさばきたい

  • 並列処理 — Parallel::ForkManager
  • 非同期処理 — IO::Async と Mojo::IOLoop

テスト・依存関係・クラス設計を整えたい

  • Test2 — Test2::V0 で書くテスト
  • Carton/cpanfile — 依存モジュールをチームでそろえる
  • Moo/Moose — bless から一歩進んだクラス設計
  • CPAN モジュール20選 — 必要なモジュールを探す

企画とコミュニティ

  • 初日のあいさつ — この企画のねらい
  • Perl の歴史とコミュニティ — CPAN・YAPC・Kansai.pm
  • 完走の振り返り — 25日間のまとめとこれから
