第1幕: 暗い区画

先週の土曜の紙面で、僕が作った潮位のグラフの最高潮位が、気象台の発表と合わなかった。紙面のほうが三センチ低い。読者からの電話で知った。どこで値が壊れたのか、まだ分からない。訂正を出すには、その原因を一行で書かなければならない。

ヘッドランプの光の輪の中で、錆の粉が舞っていた。

船尾側の区画の中は、思っていたより暗かった。照明は、入り口の近くに据えた仮設の投光器が一つだけだ。その白い光は、二つ目の壁のあたりで力尽きる。そこから奥は、額のランプが照らす分しか見えない。

壁に光を当てて、扉を数えた。

一つ。二つ。三つ。四つ。

船の中を前後に仕切る鋼の壁が、等間隔に並んでいる。壁ごとに、楕円の扉が一枚ずつ付いている。手帳に「扉 四」と書いた。連載のメモには、数が要る。読者は数字で場面を思い浮かべる。

錆と泥の匂いがした。その下に、溜まった水の冷たい匂いが混じっている。甲板の上では発電機が鳴っていて、その振動が床の鋼から靴底に上がってくる。

仕事の件は、鞄の中にある。昨夜の印刷の束だ。ここで考えることではない。今日は取材で来ている。

もう一度、扉を数え直した。四つで合っている。

「すみません。ライトを、足元に向けていただけますか」

声は、奥の暗がりから先に来た。

慌てて顎を引いた。光の輪が壁から床へ落ちて、自分の靴の先と、その先の床の段差を照らした。

足音が近づいてきた。暗がりから、人の形が光の中に入ってくる。

汐見さんだった。作業つなぎの上半身を脱いで腰で結び、上は長袖のTシャツに薄手の防寒着を羽織っている。首にタオル。腰には、白い粉で汚れた布の袋を下げている。片手に、黒いゴムの帯を輪にした束を何本も提げていた。

「ありがとうございます。目に入ると、しばらく足元が見えなくなるので」

そう言って、汐見さんはゴムの束を、僕の腕に預けた。思ったより重い。手帳とペンを持っていた手が、それで塞がった。

「これ、どう持てば」

「ゴムの面を、内側にしてください」

言われたとおりに持ち替えた。汐見さんは、防寒着のポケットから小さな機械を出して、画面を一度見た。閉じた区画に入る前に、空気を確かめる携帯のガス検知器だと、さっき入り口で教わった。表示を確かめると、またポケットに戻した。

ここは、水密区画と呼ぶ。船の中を壁で仕切った部屋のことで、一つの部屋に水が入っても、隣へ広がらないようにしてある。仕切りの壁を隔壁、隔壁の出入り口の扉を水密扉という。閉めると、水を通さない扉だ。

「今日は、扉にガスケットを付け直して、一つずつ閉めていきます」

ガスケットは、扉と枠のすき間をふさぐゴムの帯だという。僕の腕の中にある束が、それだ。二十年、海の底にあった扉のゴムは、もう使えない。仮のものに付け替える。

「付けたら、当たりを確かめます。枠の縁にチョークを塗って、扉を閉めて、開けます。ゴムの側に、チョークの線が途切れずに一周移っていれば、全周で枠に当たっています。途切れた所は、当たっていません」

汐見さんは、腰の袋を軽く叩いた。白い粉が、光の中に少しだけ浮いた。

「区画は五つで、扉は四つです。船首側から、一、二、三、四、五」

胸ポケットの防水の野帳が、汐見さんの手の中で開いた。

「三つは確かめ終えました。一と二の間、三と四の間、四と五の間です。二と三の間の扉は、ガスケットを付けましたが、枠の下の縁に泥と錆が残っていて、まだ確かめていません」

手帳に書いた。扉 四。確かめ済み 三。二と三の間、まだ。

汐見さんは、ヘッドランプを奥へ向けた。光が、いちばん後ろの区画の床を照らした。床に、黒い水が溜まっている。

「区画五の底です。昨夜の雨が溜まりました。船尾が少し低いので、入った水は後ろへ流れて、あそこに集まります。区画を閉じ切る前に、水の入り口を見つけて塞ぎたいんです」

「どこから入ったかは、分かっているんですか」

「まだ分かりません。甲板には、開口がいくつもあります」

それだけだった。分かっていることと、分かっていないことの境目で、汐見さんは言葉を止めた。

僕は、鞄の脇ポケットの IC レコーダーに手を伸ばした。赤いランプが点いている。取材の録音だ。親指で停止のボタンを押した。ランプが消えた。

少し、間を置いた。取材の相手に、自分の失敗を話すのは筋が違う。分かっていて、口が開いた。

「取材とは関係ない話なんですが。僕も今、どこから来たのか分からないものを探していて」

汐見さんは、野帳を閉じた。

「沿岸日報の土曜の紙面に、港の潮位のコラムがあるんです。来週の大潮の予報と、先週の実測の振り返り。実測のグラフは、僕が作っています」

検潮所というのは、海面の高さを毎日休まず測っている観測所だ。気象台は、そこで測った潮位を、一分ごとの値として公開している。僕はその一日分のデータを、自分で書いた集計の関数に通して、紙面のグラフを作る。一時間ごとの潮位の折れ線と、その日の最高潮位と、その時刻。

「先週の土曜の最高潮位を、紙面には一・八〇メートルと載せました。気象台の発表は、一・八三メートルです。三センチ、紙面のほうが低い。時刻も一分ずれていました」

汐見さんは、腕を組まずに聞いていた。

「釣り船の船長さんから、電話をもらったんです。紙面の値は発表より低い、って。見たら、そのとおりでした」

声が小さくなったのが、自分で分かった。

「訂正を出します。でも、うちの社では、訂正の原稿に、誤りの原因を一行書く決まりがあって。その一行が、書けないんです」

「どう、調べましたか」

「関数の、全部の段の後に、ログを足しました」

鞄の口に手を入れた。昨夜の印刷の束の角に指が触れた。束を半分引き出したところで、区画の空気の湿り気が、指先の紙に移るのが分かった。紙が、もう波打ち始めている。

束を、鞄の中に押し戻した。

「画面で見せます」

腕のゴムの束を床に置いていいかと訊こうとして、汐見さんの顔を見た。汐見さんは、黙って片手を伸ばしかけて、止めた。まだいい、ということらしい。束を片腕に抱え直して、もう片方の手でノートパソコンを開いた。

中身は、上から順に八つの段が並んでいる。社内に、この道具を書ける人はいなかった。データ報道の担当になって四年、独学の Go で、一人で書いてきた。段ごとに、何をするかのコメントを付けてある。

  1. CSV を読む（時刻と、センチメートルの潮位）

  3. 時刻を日本時間に揃える

言葉を、一つずつ足しておく。欠測は、観測の機械が何かの理由で値を記録できなかった一分のことだ。気象台のデータでは、その行に 9999 という印が入る。補間は、欠けた値を、前後の値から推し量って埋めること。

移動平均は、ある時刻の値を、その前後の数点の平均に置き換えて、細かい揺れをならす計算だ。

基準面は、潮位をどこから測るかの高さの起点で、紙面では東京湾の平均の海面（T.P.）からの高さで載せている。観測の起点からは、決まった値を引けば換算できる。

その二つを見て、外れたら処理を止める検査の関数を書いた。

言葉の意味を、ここで決めておく。検査が値に合格を出して、処理が先へ進むことを、通る、と呼ぶ。検査が値を不合格にして、処理を止めることを、止まる、と呼ぶ。

関数の本体には、手を入れたくなかった。紙面に使っている関数だ。だから、関数の写しを作って、写しのほうの段の間に、検査を呼ぶ行を一行だけ差し込めるようにした。at(4, rows) は、段4を出たところで、検査を一つ呼ぶ。

検査は値を読むだけで、書き換えない。差し込むのは原因が分かるまでで、終わったら写しごと消す。

func Range(loCm, hiCm float64, n int) Fence {

		if stage <= 6 && len(rows) != n {
			return fmt.Errorf("段%d(%s)の後: 行数 %d、本来は %d", stage, StageNames[stage], len(rows), n)

// Reference は「その地点の各行が、手で計算した参照と合っているか」を見る柵。
func Reference(want map[int][]Want) Fence {
	return func(stage int, rows []Sample) error {
		w, ok := want[stage]
		if !ok {
			return nil
		}
		if len(rows) != len(w) {
			return fmt.Errorf("段%d(%s)の後: 行数 %d、参照は %d", stage, StageNames[stage], len(rows), len(w))
		}
		for i, r := range rows {
			if math.Abs(r.Cm-w[i].Cm) > 1e-6 || r.Missing != w[i].Missing {
				return fmt.Errorf("段%d(%s)の後: 行 %d (%s) は %.1f (欠測=%v)、参照は %.1f (欠測=%v)",
					stage, StageNames[stage], i, r.Time.Format("15:04"), r.Cm, r.Missing, w[i].Cm, w[i].Missing)
			}
		}
		return nil
	}
}

訂正の記事と同じで、直したことで何が変わり、何が変わらないかを、条件を付けて書いておく。

直しても、ほとんどの日のグラフは変わらない。欠測の無い日は、直す前と同じグラフになる。夜の 20:30 に欠測が一つある日も、干潮に近い深夜二時に欠測がある日も、テスト（TestEquivalenceRange）で流して、毎時の値と最高潮位と時刻が、直す前と一致した。

変わるのは、欠測の直後の点が上書きされて、それが毎時の値か最高潮位に効く日だけだ。先週のように満潮の直前に欠測がある日が、そうだ。19:59 に欠測があって、直後の 20:00 が毎時の値になる日もそうだ。この二つは、直す前と違うグラフになる。違ってよい日だ。

  • 調べ方: Wolf Fence。処理の途中に、その地点で値がまだ正しいかの検査（柵）を立て、壊れたのが柵の前か後かで、探す範囲を半分にしていきます
  • 固定したもの: 15行の手作りの入力と、手で計算した出口の値を、TestSmallInputExit として残しました。柵は写しごと消しました。訂正の原稿の原因の一行に、段の名前を書きました
