変数とサブルーチンだけで書いていたPerlを、Mooのクラスで整理する全12回【目次】

変数とサブルーチンだけで書いた Perl は、データと処理が散らばり、どこで値が変わったのか追えなくなる。Moo で掲示板アプリを1つ育てながら、クラス・カプセル化・継承・ロール・委譲・型制約まで、オブジェクト指向の基本を1回に1つずつ身につける全12回の案内板です。

02, 2026
読了時間: 4分

Perl の Moo を使って、オブジェクト指向プログラミングの基本を1回に1つずつ身につける全12回の連載です。第1回で Moo の書き方に慣れたあとは1つの掲示板アプリが題材で、第2回の投稿を表す Message クラスから始めて、User・AdminMessage・Board と、回を追うごとにクラスを増やしながら育てていきます。

各回は短く、前の回のコードを少しずつ直していく作りなので、通して読むなら第1回からが早道です。このページは目次を兼ねた案内板です。入口は「どこから読むか」で、困りごとが決まっているなら「困りごとから探す」で、順に追うなら「全話一覧」で選んでください。

対象は、Perl の変数・サブルーチン・配列とハッシュが分かり、cpanm などでモジュールを入れられる方です。bless を使ったオブジェクト指向は知らなくてかまいません。

どこから読むか

  • 第1回 — オブジェクト指向を初めて学ぶなら。数行のクラスを動かし、オブジェクト・クラス・プロパティ・メソッドの4つの用語を押さえる回
  • 第4回 — クラスは書けるが、値をどう守ればいいか分からないなら。読み取り専用・必須・カプセル化と続く第6回までの3回で、守り方をひととおり押さえる
  • 第8回 — 継承は知っているが、使いどころに迷うなら。継承・オーバーライド・ロール・委譲と、クラスどうしのつなぎ方を第11回まで比べながら読める

困りごとから探す

データと処理があちこちに散らばっている

  • 第2回 — 投稿のデータがグローバル変数に散らばり、どれが何のデータか分からない
  • 第3回 — 変数名に番号を振って、コピペで増やしている

値がいつの間にか変わっている、おかしな値が入っている

  • 第4回 — 一度決めた値が、どこかで書き換えられている
  • 第5回 — 渡し忘れた値が空のまま通っている
  • 第6回 — いいね数がマイナスになっている
  • 第12回 — 数値のはずの属性に文字列が入っている

クラスが太って、何をするクラスか分からない

  • 第7回 — 別の物のデータまで1つのクラスに溜まっている
  • 第11回 — 配列操作のようなメソッドが増えて、本来の処理が埋もれている

似たクラスで、同じコードを何度も書いている

  • 第8回 — よく似たクラスに、属性とメソッドを丸ごと書き写している
  • 第9回 — クラスの種類ごとに if 文で分岐している
  • 第10回 — 親子関係にない2つのクラスに、同じ機能が要る

全話一覧

  • 第1回 Perlのオブジェクト指向をblessから覚えようとして、つまずいている。Mooで数行のクラスを動かす【Moo】
  • 第2回 グローバル変数が散らばり、どれがどの投稿のデータか分からない。データと処理を1つのクラスにまとめる【hasとsub】
  • 第3回 変数名に番号を振ってコピペで増やしている。同じ形のオブジェクトを何個でも作る【コンストラクタ】
  • 第4回 一度投稿した内容が、どこかで書き換わっている。属性を読み取り専用にする【roとrw】
  • 第5回 渡し忘れた値が空のまま通り、離れた所で発覚する。必須の属性と初期値を決める【requiredとdefault】
  • 第6回 いいね数がマイナスになっている。内部の値を隠し、メソッド経由でしか変えさせない【カプセル化】
  • 第7回 Messageクラスに投稿者の属性まで溜まり、なんでも屋になった。投稿者を別クラスに分ける【クラスの連携】
  • 第8回 管理者用のクラスに、同じ属性とメソッドを丸ごと書き写した。共通部分を親クラスにまとめる【継承】
  • 第9回 クラスが増えるたびに、表示処理のif文が伸びていく。子クラスでメソッドを上書きする【オーバーライド】
  • 第10回 MessageにもUserにも作成日時が要るが、親子関係にするのは不自然。継承せずに機能を足す【ロール】
  • 第11回 掲示板クラスが配列操作のメソッドで埋まった。持っているオブジェクトに仕事を任せる【委譲】
  • 第12回 いいね数に「たくさん」と入っても、計算するまで気づけない。属性に型を付けて入口で弾く【型制約】
